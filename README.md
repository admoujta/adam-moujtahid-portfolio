# Moujtahid Adam — Portfolio

Personal portfolio of Moujtahid Adam, an EMSI Computer Engineering and Networks student focused on software engineering, Big Data and Artificial Intelligence.

## Contents

Projects, technical skills, academic journey, certifications and contact information.

## Technologies

Next.js, React, TypeScript, Tailwind CSS, Framer Motion and Lenis.

## Local development

From the project directory:

```bash
npm ci
npm run dev
```

## Checks and production build

```bash
npm run lint
npx tsc --noEmit
npm run build
npm start
```

## Content and assets

- `contents/en.json` and `contents/tr.json`: biography, projects and journey.
- `contents/shared.json`: contact information and skills.
- `dictionaries/`: interface labels.
- `public/projects/`: project screenshots.
- `public/cv-moujtahid-adam.pdf`: downloadable CV.

## Deployment

The repository includes `vercel.json` for Next.js deployment with `npm ci` and `npm run build`. No environment variables are currently required.
